# 16-Week Course Roadmap

| Week | Module | Topics | Deliverable |
|---:|---|---|---|
| 0 | Orientation | Tooling, terminal, browser DevTools, workflow | Working environment |
| 1 | Web & JavaScript | HTML/CSS recap, modern JS, async/await, fetch, JSON | JS exercises |
| 2 | Git & GitHub | Commits, branches, PRs, issues, Markdown | Exercise repo |
| 3 | Node.js | Runtime, npm, modules, filesystem, env vars | CLI notes app |
| 4 | Express & REST | Routing, middleware, controllers, validation, errors | REST API |
| 5 | MongoDB & Mongoose | Schemas, CRUD, indexes, references, aggregation | Database API |
| 6 | React fundamentals | JSX, components, props, state, forms, effects | Task UI |
| 7 | Advanced React | Routing, hooks, context, API client, reusable UI | Multi-page app |
| 8 | MERN integration | CORS, API integration, pagination, filtering | Full-stack task manager |
| 9 | Auth & security | Password hashing, sessions/JWT trade-offs, authorization, rate limits | Protected app |
| 10 | Testing & quality | Unit, integration, UI tests, linting, CI | Tested blog |
| 11 | AI foundations | LLMs, tokens, prompts, evaluation, hallucinations | Prompt lab |
| 12 | AI API integration | Backend model client, JSON output, streaming, tool calling | AI support assistant |
| 13 | Embeddings & RAG | Chunking, embeddings, vector search, citations, evaluation | Document Q&A |
| 14 | Deployment | Hosting, secrets, logs, health checks, CI/CD | Deployed app |
| 15 | Capstone | Planning, implementation, testing, demo | Portfolio product |

## Suggested weekly rhythm
- 2 hours: concepts and instructor walkthrough
- 3 hours: guided coding
- 2–4 hours: independent assignment
- 1–2 hours: review, testing and documentation

## Grading
Weekly exercises 20% · Module assignments 25% · Portfolio projects 25% · Capstone 30%.
