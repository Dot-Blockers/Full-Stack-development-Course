# Project 01 — MERN Task Manager

Build a multi-user task manager with CRUD, status filters, search, pagination, MongoDB persistence and responsive React UI.

Suggested API: `GET /api/tasks`, `POST /api/tasks`, `GET /api/tasks/:id`, `PATCH /api/tasks/:id`, `DELETE /api/tasks/:id`.

Stretch goals: authentication, task ownership, due dates, labels and AI task breakdown suggestions. Authorization must be enforced on the server.
