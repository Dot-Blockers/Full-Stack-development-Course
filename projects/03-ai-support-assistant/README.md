# Project 03 — AI Support Assistant

Build a React chat UI and Express backend integration with bounded history, timeouts, safe errors, feedback and human escalation.

Treat user messages as untrusted. Do not invent company policy. If using a knowledge base, cite sources. Apply rate/token limits and validate structured output.

Evaluation: at least 10 cases including normal, ambiguous, out-of-scope and prompt-injection attempts.
