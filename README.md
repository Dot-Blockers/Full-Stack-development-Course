# MERN Stack Development with AI Integration

A GitHub-ready, project-based course covering MongoDB, Express.js, React, Node.js and practical AI integration.

**Level:** Beginner to intermediate | **Duration:** 16 weeks | **Workload:** 8–12 hours/week

## Outcomes
- Build REST APIs with Express and MongoDB/Mongoose.
- Build responsive React applications and connect them to backend services.
- Implement authentication, authorization, validation, testing and deployment.
- Integrate LLM APIs securely from the backend.
- Build structured-output, streaming-chat and retrieval-augmented generation (RAG) features.
- Use GitHub issues, branches, pull requests and CI workflows professionally.

## Repository structure
```text
modules/       16 sequential modules with objectives, labs and assignments
projects/      Task Manager, MERN Blog, AI Support Assistant, Capstone
docs/          Setup, Git workflow, rubric and capstone requirements
resources/     Glossary, prompt patterns and interview preparation
templates/     Lesson, assignment and pull-request templates
```

## Start here
1. Read `COURSE-ROADMAP.md`.
2. Complete modules in order.
3. Create a Git branch for each assignment.
4. Submit work through pull requests.
5. Build the projects and document them in their own README files.

## Practical projects
1. MERN Task Manager — CRUD, filtering, pagination and user ownership.
2. MERN Publishing Platform — authoring, publishing, roles and moderation.
3. AI Support Assistant — secure model integration, bounded conversation history and escalation.
4. Capstone — deployed MERN product with a meaningful, evaluated AI feature.

## Safety
Never expose model API keys in frontend code. Treat model output and retrieved documents as untrusted input. Validate outputs, enforce authorization in application code, set rate/token limits, and document privacy and failure behavior.
