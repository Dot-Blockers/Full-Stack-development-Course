# Capstone Specification

Build and deploy a MERN product that solves a defined problem and includes one meaningful AI workflow.

Possible topics: AI-assisted learning platform, support ticket triage, knowledge-base assistant, project manager, or property-listing workflow with human-reviewed AI drafting.

## Required
1. Responsive React frontend.
2. Express REST API and MongoDB persistence.
3. Authentication and server-side authorization where user data is involved.
4. Validation, consistent errors and rate limiting.
5. At least one backend-integrated AI feature.
6. Schema validation for model output and safe failure behavior.
7. Tests for critical business rules and authorization.
8. HTTPS deployment with configured secrets.
9. README with setup, architecture, environment variables, tests and deployment.

## AI evaluation
Create at least 10 representative test cases. Record expected behavior, observed output and known failure modes. Model output alone must never authorize sensitive actions.

## Demo (8–10 minutes)
Problem, live user journey, architecture/data model, AI workflow/evaluation, security/testing, limitations and next steps.
