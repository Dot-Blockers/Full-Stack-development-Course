# Assessment Rubric

Score each criterion 0–4: 0 missing, 1 major gaps, 2 partial, 3 meets requirements, 4 excellent.

- Correctness and acceptance criteria
- Code organization and readability
- API and data-model design
- UI usability and accessibility
- Validation, security and error handling
- Automated tests
- Git history and PR quality
- Documentation and reproducibility
- AI grounding, evaluation and safeguards

A critical security failure (exposed secret, broken authorization boundary, or private-data leak) must be fixed before acceptance.
