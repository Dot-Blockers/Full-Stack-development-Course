# Interview Preparation

## JavaScript / Node
- Explain the event loop and asynchronous I/O.
- Compare `Promise.all` with sequential awaits.
- Explain error propagation and module boundaries.

## Express / MongoDB
- Describe Express middleware order.
- How do you validate and authorize an update?
- When do you embed documents vs reference them?
- Which index supports a common filter/sort query?

## React
- Props vs state?
- When is an effect appropriate?
- How do you handle stale requests and loading/error states?

## Security / AI
- Authentication vs authorization?
- Where should API keys live?
- What is RAG?
- How do you validate model output and mitigate prompt injection?
- How do you monitor token cost and latency?
