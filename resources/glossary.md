# Glossary

- API: contract through which software systems communicate.
- REST: resource-oriented API design using HTTP semantics.
- Middleware: function in a request/response processing chain.
- CRUD: create, read, update and delete.
- Authentication: establishing identity.
- Authorization: deciding what an identity may do.
- LLM: large language model.
- Token: unit of text processed by a language model.
- Embedding: vector representation used for similarity/retrieval.
- RAG: retrieval-augmented generation, grounding generation in retrieved content.
- Prompt injection: attempt to manipulate model behavior through untrusted content.
- CI/CD: continuous integration and continuous delivery/deployment.
