# Module 09 — Authentication, Authorization & Security

## Learning objectives
- Password hashing, sessions/JWT trade-offs, auth middleware, ownership checks, validation, rate limits and secure headers.

## Lessons
1. Concepts and architecture
2. Instructor walkthrough
3. Guided implementation
4. Debugging and common failure modes
5. Review, testing and documentation

## Guided lab
Add registration/login and protected user-owned tasks; submit a short threat model.

## Assignment
Extend the guided lab independently. Add edge cases, error handling and a clear README with setup instructions.

## Definition of done
- [ ] Requirements work from a clean install.
- [ ] Inputs are validated and errors are handled.
- [ ] Code is readable and organized.
- [ ] Tests or reproducible manual test steps are included.
- [ ] README explains setup, usage and limitations.

## Reflection
- What concept was most difficult?
- What did you debug, and how?
- What would you refactor before shipping?
